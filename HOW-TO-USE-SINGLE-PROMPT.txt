HOW TO USE THE SINGLE PROMPT (One-Pager)
================================================================================

## WHAT YOU HAVE

One comprehensive prompt file: **PARMANA-MONTHLY-MARKET-RESEARCH-SINGLE-PROMPT.md**

Copy and paste this prompt into Claude each month.
Takes 3-4 hours to execute.
Generates: PARMANA-MARKET-ANALYSIS-[MMYYYY].md

================================================================================
MONTHLY WORKFLOW (Copy-Paste This Every Month)
================================================================================

STEP 1: Copy the prompt file
─────────────────────────────

Last Friday of month:

  1. Open: PARMANA-MONTHLY-MARKET-RESEARCH-SINGLE-PROMPT.md
  2. Copy entire text
  3. Paste into Claude chat
  4. Edit only these 3 fields at the top:
     - [CURRENT_MONTH] = September (or October, etc.)
     - [CURRENT_YEAR] = 2026
     - [PREVIOUS_MONTH_REPORT_DATE] = August 24, 2026 (or your previous date)
  5. Hit Enter/Send


STEP 2: Execute (Follow prompt instructions)
────────────────────────────────────────────

The prompt tells you exactly what to do:

  STEP 1: Run 38 searches (web_search enabled)
          → Copy-paste search queries from prompt
          → Run in Claude
          → Compile findings
  
  STEP 2: Organize findings
          → Create ~15-20 finding blocks
          → Use template provided in prompt
  
  STEP 3: Generate report
          → Copy report structure from prompt
          → Fill each section with your findings
  
  STEP 4: Check quality
          → Use checklist in prompt
          → Do 15-min peer review
  
  STEP 5: Publish
          → Save as: PARMANA-MARKET-ANALYSIS-[MMYYYY].md
          → File in: /mnt/user-data/outputs/
          → Notify team


STEP 3: Save the output
───────────────────────

Filename: PARMANA-MARKET-ANALYSIS-[MMYYYY].md

Examples:
  - PARMANA-MARKET-ANALYSIS-092026.md (September 2026)
  - PARMANA-MARKET-ANALYSIS-102026.md (October 2026)
  - PARMANA-MARKET-ANALYSIS-112026.md (November 2026)

Location: /mnt/user-data/outputs/

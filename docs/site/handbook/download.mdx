<script
  dangerouslySetInnerHTML={{
    __html: `
      (function () {
        var form = document.getElementById("handbook-download-form");
        var status = document.getElementById("handbook-download-status");
        if (!form) return;
        form.addEventListener("submit", function (event) {
          event.preventDefault();
          var email = document.getElementById("handbook-download-email").value;
          status.textContent = "Requesting...";
          fetch("https://parmana-api-real.vercel.app/handbook/download-leads", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ email: email }),
          })
            .then(function (res) {
              if (!res.ok) throw new Error("Request failed");
              return res.json();
            })
            .then(function (data) {
              status.innerHTML =
                'Thanks. <a href="' +
                data.downloadUrl +
                '" download>Click here if the download does not start automatically</a>.';
              window.location.href = data.downloadUrl;
            })
            .catch(function () {
              status.textContent =
                "Something went wrong. You can also read every chapter directly on this site, starting from the Handbook overview page.";
            });
        });
      })();
    `,
  }}
/>

## What you're downloading

The complete Parmana Handbook: 23 chapters, every
capability this codebase has, explained by reading the actual source. See the
[overview page](/handbook/overview) for the full chapter list, or read any
chapter directly on this site without downloading anything. The PDF is generated
from the exact same source files as the pages on this site
(`docs/parmana-handbook/*.md` in the repository), by
`scripts/generate-handbook-pdf.ts`. It is not a separately-maintained document
that can drift from what's published here.

Per-package test counts below come from running `vitest run packages/<name>` one package at a
time, not from the repo root (see the note below for why). Run `npm test` from the repo root
for the current whole-repo total.

<Note>
  Running `vitest run` once from the repo root instead of per-package produces
  spurious failures in `packages/runtime`: several tests resolve fixture paths
  relative to `process.cwd()`, which assumes a per-package invocation. This is a
  pre-existing test-path fragility, not a functional bug, see
  [Troubleshooting](/troubleshooting).
</Note>
